Outliner

Drag a shape to start

Pick from the left toolbar, drop it on the workplane. Click any shape to edit dimensions and colour.

  • 1Drag a primitive (box, cylinder, sphere…) from the left.
  • 2Drag the body to move. Use the white handles to resize. Right-click + drag orbits the camera.
  • 3Add a second shape, mark it as Hole in Properties, select both, Ctrl+G to combine.
  • 4Export STL when ready. Save the project with Ctrl+S.

Press Ctrl+K any time for the full keyboard shortcut list. Hover any toolbar control for an inline explanation.

Help & shortcuts

Mouse
L-click select shape
L-drag body → move on XY
R-drag orbit camera
Shift+R-drag → pan
Scroll zoom
Shift+L-click add to selection
Ctrl+L-click toggle in selection
Drag in empty space → marquee select
Handles (white squares)
Top corner → resize X+Y simultaneously
Top mid-edge → resize one axis
Top centre square → resize Z (height)
Top arrow → move on Z
Coloured arc → rotate around axis (snaps 0.1° · hold Shift for 15° increments · hold Ctrl to bypass all snap)
Shift uniform scale · Alt from centre · Ctrl bypass snap
Operations
Group → combine selected with CSG (holes carve, solids merge)
Ungroup → restore the unbaked group's original parts
Bake → finalise group, delete child parts (permanent)
Split SOON → coming soon; algorithm being rewritten
Cut → slice the shape along an X/Y/Z plane in two halves
Align → snap selected shapes' edges/centres to one axis
Mirror → flip selected shapes across an axis
Drop → place the active shape on the workplane (Z = 0)
Hide → toggle a shape's visibility (keeps it in scene)
Keyboard
Ctrl+Z undo · Ctrl+Shift+Z redo
Ctrl+S save project · Ctrl+D duplicate · Ctrl+G group
Ctrl+A select all · Esc deselect
Del/⌫ delete selected
D drop to workplane · H hide
R/S rotate / scale gizmo
1/3/7 front / right / top view
0 iso · F fit to scene
Settings (gear icon ⚙)
Switch theme · show/hide grid, axes, viewcube, HUD · toggle shadows for perf
