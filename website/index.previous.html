Everything you need to model for 3D printing.

13 primitive shapes, full CSG (union + subtraction), STL/OBJ import-export, sketches, slicing, hollowing, arrays, ruler. All running locally on your machine.

Solid + Hole CSG

Group shapes and the holes carve, solids merge. Reversible until you bake. Powered by three-bvh-csg.

STL / OBJ / STEP export

Bring in any mesh as an editable shape. Export the whole scene to printer-ready binary STL, Wavefront OBJ, or AP203 faceted-brep STEP for CAD/CAM pipelines.

Sketch tools

Extrude polygons, scribble free-hand outlines, revolve profiles into lathe-style solids. Custom geometry without leaving the app.

Cut along plane

Bambu-style cut. Slice a shape along X, Y, or Z into two halves with a live plane preview.

Hollow / Shell

Carve the inside of any shape with a chosen wall thickness. Print-ready shells in two clicks.

Ruler with vertex snap

Click two points. Get distance + per-axis deltas. Locks onto vertices so measurements are exact.

Linear + circular arrays

N copies along a line with spacing, or around an axis with a chosen total angle. Saves dozens of clicks.

Workplane on face

Drop the active workplane on any face. New shapes spawn aligned to that face's normal.

Volume + surface area

Live numbers in the Properties panel. Estimate filament cost without leaving the app.

From idea to printable STL in four steps.

Five minutes from first launch to a printed bracket.

  1. 1

    Drop in a shape

    Drag any of the 13 primitives from the left panel onto the workplane. Each one has size and segment knobs in the Properties panel.

  2. 2

    Mark shapes as Hole

    Toggle a shape to Hole and it carves into anything it overlaps with after Group. This is how you cut slots, drill holes, hollow blocks, anything.

  3. 3

    Group to combine

    Select multiple shapes, hit Group. Solids merge, holes subtract. Reversible until you Bake. Live CSG via three-bvh-csg, fast even on big STL imports.

  4. 4

    Export STL → slice → print

    Click STL in the top-right. Open the file in Bambu Studio, Cura, PrusaSlicer, or whatever you use. Done.

Questions, answered.

The honest answers. If something here is unclear, email geral@marjers.com.

Is it really free?

Yes. Free for personal use, no time limit, no feature lockout, no nag screens you can't dismiss. The €12 commercial licence is for people who want to use exports in for-profit work (selling prints, freelance, classroom use) and to silence the occasional reminder dialog. Everyone else can use it forever for €0.

Do I need an account or internet connection?

No. Both. Once installed, the app never makes a network request. Your work stays on your machine. No telemetry, no analytics, no auto-uploads.

Where is my work saved?

Two places. Autosave: localStorage in the app's profile folder, restored on next launch. Project files: standard .json on disk that you save explicitly. STL/OBJ exports go wherever your browser/Electron downloads land (usually Downloads/).

Why does Windows show a SmartScreen warning?

Because the binary is new and SmartScreen hasn't yet built reputation for it. Click "More info" → "Run anyway" and it goes away forever for that install. Once enough people install BlockBuilder, the warning disappears for everyone. Builds are code-signed; the binary is genuinely from Marjers and contains no malware. You can verify the signature in the .exe properties.

Can I use it commercially?

Yes, with a one-time €12 commercial licence at marjers.com/blockbuilder. Covers selling prints, freelance work, paid classroom use, agency work, anything for-profit. Personal/hobby use stays free.

Is this CAD?

Not in the engineering sense. BlockBuilder is a direct modelling tool: you drag primitives, scale them, combine them with booleans. There's no parametric history, no constraints, no assemblies, no engineering drawings. It's optimised for the 80 % of 3D-printing work that doesn't need those features, brackets, organisers, replacement parts, props, jigs. For mechanical engineering with version-controlled geometry, use a parametric CAD package.

Can I import existing STL or OBJ files?

Yes. Drag any .stl or .obj into the viewport (or use the Import button). Imported meshes behave like primitives: move, scale, rotate, colour, mark as Hole, group with others, run CSG against them. Big meshes (100k+ triangles) get an automatic BVH for fast picking.

Can I export to STEP?

Yes, with a caveat. BlockBuilder works internally with triangle meshes, not parametric CAD surfaces. The STEP export wraps the mesh in an AP203 faceted B-Rep file that Fusion 360, SolidWorks, FreeCAD, Onshape and most CAD/CAM tools will open as a mesh body. You won't get editable parametric features (no fillets to drag, no cylinders to re-radius) because the source geometry is already tessellated. If you need true parametric STEP, model in a parametric CAD package from the start. For passing geometry to a CNC shop or CAM pipeline that requires STEP, this is a working option.

What if my STL fails the boolean operation?

Imported meshes need to be watertight (manifold) for CSG. Use the Repair button in the Properties panel: it welds duplicate vertices, drops zero-area triangles, and rebuilds normals. Resolves most failures. If the original mesh has actual holes/non-manifold edges, no software can fix that without topology repair.

Is the source code available?

Not yet. Open-sourcing is on the roadmap once the code is more polished. The Electron + Three.js stack is well-known, no proprietary dependencies, so the timeline is mostly about cleaning up.

How do I get help or report bugs?

Email geral@marjers.com with a description and, if possible, the saved .json that triggers the bug. Replies usually within 48 hours.

What about touchscreens / iPads / phones?

Not supported. BlockBuilder is desktop-only (mouse + keyboard). The 3D viewport relies on right-click orbit, scroll-zoom, and precise pointer hits that don't translate well to touch. A web version may come later.
